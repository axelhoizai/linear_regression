
# 📉​ linear_regression

**linear_regression** is an introductory project to **machine learning** focused on implementing a **linear regression model from scratch**.  
The goal is to predict the **price of a car based on its mileage** using a **gradient descent algorithm**, without relying on advanced ML libraries.  

This project emphasizes understanding the **mathematical foundations of regression** and how optimization algorithms work.  

---

## 🧠 New skills unlocked  

- **Machine Learning Basics** → Understanding supervised learning and regression models  
- **Gradient Descent** → Implementing and tuning an optimization algorithm  
- **Data Handling** → Using **Pandas** to clean and manipulate datasets  
- **Numerical Computation** → Working with **NumPy** for efficient calculations  
- **Data Visualization** → Plotting regression lines and data with **Matplotlib**  
- **Model Evaluation** → Measuring prediction accuracy and improving performance  

---

## 🏗️ Project Requirements  

### 🎯 Objectives  
- Implement a **linear regression model** from scratch  
- Use **gradient descent** to optimize model parameters (`θ0`, `θ1`)  
- Predict a car price based on its **mileage**  
- Normalize data to improve convergence  
- Store and reuse trained model parameters  

---

## ⚙️ Constraints  

- Allowed libraries:  
  - **Pandas**  
  - **NumPy**  
  - **Matplotlib.pyplot**  
- Forbidden:  
  - Machine learning libraries such as **scikit-learn** or **numpy.polyfit**
